DeductIT is a web-based educational tool for practising natural deduction proofs.
The system includes a React frontend and a Node.js backend proof checker.

After downloading the project, extract the folder to a location on your computer and open the project directory in a terminal.

Requirements

Node.js installed

npm installed

Modern web browser (Chrome, Edge, or Firefox)

Running the System

Open a terminal in the frontend folder and run:

npm install
npm start

Open another terminal in the backend folder and run:

npm install
npm start

Open a browser and navigate to:

http://localhost:3000

Both the frontend and backend must be running at the same time for the system to function correctly.
