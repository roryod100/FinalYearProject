DeductIT is an interactive web-based educational tool designed 
to help students practise natural deduction proofs in propositional
 and predicate logic. The system provides a structured interface 
 where users can construct proofs step by step by selecting logical 
 symbols, applying inference rules, and building subproofs. 
 A backend proof-checking engine validates each completed proof to
ensure that the rules of natural deduction are applied correctly.

The application is built using a React frontend and a Node.js/Express
 backend. It aims to make learning formal logic more engaging by providing 
 immediate feedback, visual guidance, and a guided tutorial for new users.

 **TO RUN DEDUCTIT**
Open two terminals:
Backend:
cd backend
npm install
npm start  
Runs at localhost:5000.
Frontend:
cd frontend
npm install
npm start  
Runs at localhost:3000.
Keep both terminals running while using the project.
